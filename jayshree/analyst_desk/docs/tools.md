## filings-kb

Module: `analystdesk.servers.filings_kb`

### `search_filings`

Search 10-K passages with BM25 + vectors (RRF) and a cross-encoder reranker.

With no company filter, a question naming several companies or years is
split into one search per company/year so each gets evidence.

Annotations: readOnlyHint=True, destructiveHint=False

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | yes | What to look for, in plain words  |
| `company` | string or null | no | Ticker filter, e.g. MSFT. Omit to search the companies named in the query. (default null) |
| `fiscal_year` | integer or null | no | Fiscal year filter, 2022-2024 (default null) |
| `item` | string or null | no | item1a (Risk Factors) or item7 (MD&A) (default null) |
| `top_k` | integer | no | Number of passages to return (default 5, min 1, max 20) |

Output fields: `ok`, `error`, `passages`

### `get_passage`

### `get_financials`

Revenue, operating income and pre-tax income for one company and fiscal year.

By default the earliest matching cached annual 10-K or 10-K/A value is
unverified. With a reviewed-source register configured, only explicitly
eligible facts and versions are returned. The register does not itself verify
reviewer identity, issuer evidence or non-reliance; see `product_spec.md`.

Annotations: readOnlyHint=True, destructiveHint=False

| Parameter | Type | Required | Description |
|---|---|---|---|
| `ticker` | string | yes | Ticker, e.g. MSFT  |
| `fiscal_year` | integer | yes | Fiscal year (year the period ends), 2022-2024  |

Output fields: `ok`, `error`, `ticker`, `company`, `fiscal_year`, `margin_basis`, `revenue`, `operating_income`, `pretax_income`, `warnings`

### `get_fact`

Look up the exact value that a fact_id refers to.

Matches the concept, the fiscal year and the very filing (accession) the
fact_id names — used to verify every number cited in a note.
Configured source-review decisions also restrict exact fact lookup.

Annotations: readOnlyHint=True, destructiveHint=False

| Parameter | Type | Required | Description |
|---|---|---|---|
| `fact_id` | string | yes | concept/fiscal_year/accession, e.g. OperatingIncomeLoss/2024/0000950170-24-087843  |

Output fields: `ok`, `error`, `ticker`, `fact`

### `publish_note`

WRITE — publish a research note to the portal.

Refused unless approval_token was issued for exactly this title, body and
ticker list. Any edit after approval requires a new approval. Once an
approver public key is registered, also refused without that approver's
own signature over the note digest.

Annotations: readOnlyHint=False, destructiveHint=False

| Parameter | Type | Required | Description |
|---|---|---|---|
| `title` | string | yes | Note title, exactly as approved  |
| `body` | string | yes | Note body, exactly as approved  |
| `tickers` | array | yes | Tickers the note covers, as approved  |
| `approval_token` | string | yes | Token issued when the analyst approved this exact note  |
| `approver_signature` | string or null | no | The approver's own Ed25519 signature over the note's sha256 digest, base64url. Required once an approver public key is registered (see servers/signing.py) (default null) |

Output fields: `ok`, `error`, `note_id`, `note_sha256`, `published_at`
