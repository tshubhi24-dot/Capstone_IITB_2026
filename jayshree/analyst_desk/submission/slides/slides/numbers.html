Signature challenge A

Numbers you can trust

1 · Writer

writes a placeholder, e.g. {MSFT_2024_margin}, never the number

2 · Code

fetches the XBRL fact, computes, rounds, inserts “44.64%” with its fact id

3 · Checker

re-derives every figure: value, sign, scale, company, year, basis

4 · Gate

approval refused while any check fails

Like-for-like: Microsoft’s year ends in June, Alphabet’s in December; banks on pre-tax margin; Apple’s 53-week FY2023. The note states each, in code.

Traps closed: “$2.2K” never matches “$2.2 billion”; no growth rate from a loss; a ratio can’t mix companies or years.

The model chooses which figure to mention; code decides what it says. Every number in a note is either a code-rendered XBRL figure with its fact id, or a quote that must appear with the same unit in the passage cited on the same line.
