## Role handoffs

R1 defines useful questions, expected answers, acceptable interpretations, limitations and domain acceptance. R2 supports source and memory quality; R3 implements task execution; R4 enforces controls; R5 independently evaluates; R6 implements serving, UI and operations. Completed specifications and review findings do not establish that every control or shared experiment is complete.
